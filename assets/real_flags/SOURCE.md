# Real Flag Assets

Source: https://github.com/hampusborgos/country-flags/tree/main/svg

These SVGs are copied from `hampusborgos/country-flags`, whose README describes them as accurate country and territory flag renders organized by ISO country code.

The source README states the flags are not under copyright protection because flags are in the public domain, while noting there may be other restrictions on how some flags can be used.

## Exception: xs.svg (Somaliland)

Somaliland has no ISO 3166 code, so `hampusborgos/country-flags` doesn't include it.
`xs.svg` is instead https://commons.wikimedia.org/wiki/File:Flag_of_Somaliland_(3-2).svg,
which uses the flag's official 3:2 proportions (matching this app's own `xs` convention,
already used by `countries_colors`/`assets/color_flags/xs.svg`). Public domain as a flag,
same as the rest of this set.
